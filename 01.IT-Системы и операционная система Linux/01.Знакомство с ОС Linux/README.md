```

export PS1_OLD="\$PS1"
export PS1='\u@\h:\w \$ (Сергеева Людмила Владимировна)'
echo "\$PS1"
pwd
bash --version
source ~/.bashrc

source ~/.bashrc

```

![alt text](<Screenshots/Задание 1-2.png>)

```
В рамках задания в гостевой ОС Ubuntu (VirtualBox) настроено пользовательское приглашение Bash через переменную PS1 с отображением ФИО «Сергеева Людмила Владимировна» в строке ввода.
Для персонализации и быстрой идентификации сессии реализовано цветовое оформление (имя пользователя — зелёным, хост и путь — синим) с корректным экранированием непечатаемых символов (\[ и \]) — это сохраняет работоспособность автодополнения и очистки экрана. Исходное значение PS1 сохранено в PS1_OLD для возможности отката.
Результат подтверждён скриншотом терминала: в строке приглашения отображается ФИО, видны элементы сессии (пользователь, хост, путь) и пример выполненной команды. Настройка демонстрирует навыки безопасной модификации окружения Linux.

```

- export PS1_OLD="$PS1"
- export PS1="\u@\h:\w \$ \[\033[33m\](ФИО: Сергеева Людмила Владимировна)\[\033[0m\] "
- bash --version
- source ~/.bashrc

```


![alt text](<Screenshots/Задание 1-3.png>)


```

В ходе работы в гостевой ОС Ubuntu (VirtualBox) настроено приглашение командной строки Bash с отображением ФИО пользователя.
  Для безопасного изменения конфигурации исходное значение переменной PS1 сохранено в PS1_OLD.
В строку приглашения (PS1) добавлено текстовое поле (ФИО: Сергеева Людмила Владимировна) с жёлтым цветом через ANSI‑коды \[\033[33m\] и сбросом цвета \[\033[0m\].
Версия оболочки Bash — 5.1.16, что подтверждает корректность работы спецсимволов в приглашении.
Изменения применены в текущей сессии командой source ~/.bashrc.
Результат подтверждён скриншотом консоли, на котором видно приглашение терминала с цветным ФИО.

```
