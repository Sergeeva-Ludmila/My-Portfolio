## Задание 2. Утилита htop

1. Установите утилиту *htop*
2. С помощью *htop* ответьте на вопросы:
- Какие процессы занимают больше всего памяти?
- Какие процессы занимают больше всего процессорного времени?

*Приведите ответ в виде снимков экрана*

## Ответ:

```
htop - это интерактивная утилита для мониторинга системы в Linux: она в реальном времени показывает запущенные процессы, нагрузку на CPU, использование памяти и позволяет ими управлять прямо из терминала.

ps — это стандартная утилита в Linux, которая показывает список запущенных процессов и их текущее состояние.

Значения %MEM и %CPU могут отличаться от тех, что видны в htop, потому что ps делает разовый снимок, а htop показывает динамические метрики с периодическим обновлением.

Для выполнения этого задания и чтобы ответить на вопросы было сделано:
- установлена утилита htop
- использована утилита htop и ps

```

## Задание 3. Работа с сетью

1. Добавьте в виртуальную машину два дополнительных сетевых адаптера с внутренней (internal) сетью

3. Настройте на втором из них адрес *10.2.0.1* маску подсети *255.0.0.0*
4. На обоих интерфейсах настройте адрес *dns-сервера* как *8.8.8.8* и шлюз по умолчанию *10.1.1.1*
5. Выполните команду *ip addr*
